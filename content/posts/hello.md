Welcome to your new site. This starter post shows what the build does with plain Markdown — delete it and put your own writing in `content/posts/`.

## Code

Fenced blocks are syntax-highlighted with Shiki in both light and dark themes:

```rust
fn main() {
    println!("hello, world");
}
```

## Notes and links

Footnotes render as margin notes on wide screens[^1] and tap-to-expand notes on narrow ones.

[^1]: Like this one.

## Everything else

Posts with three or more `##` sections automatically get a contents list. Reading-list entries, CVE disclosures, and your about page are driven by JSON in `data/` — see the README.
