# Contributing

This is a small, deliberate template — no framework, one build script you can read in an afternoon. Keep it that way.

- Bugs and doc fixes: open an issue first, or a small PR is fine.
- Features: open an issue and make the case before writing code. The bar is "does this complicate the build for everyone?" — most ideas fail that bar.
- The template stays dependency-light and bundle-free by design.
